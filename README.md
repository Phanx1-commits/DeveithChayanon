# Resume site

เรซูเม่หน้าเดียวภาษาไทย สร้างด้วย React, TSX และ Tailwind CSS

## เริ่มต้นใช้งาน

```bash
npm run dev
```

จากนั้นเปิด `http://localhost:5173`

## แก้ไขข้อมูล

แก้ชื่อ ประสบการณ์ ผลงาน ทักษะ และช่องทางติดต่อได้ที่ `app/page.tsx`

ปุ่ม “ดาวน์โหลด PDF” ใช้หน้าต่างพิมพ์ของเบราว์เซอร์เพื่อบันทึกเป็น PDF

## ตรวจ build

```bash
npm run build
```
